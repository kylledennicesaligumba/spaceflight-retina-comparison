# Local data

Download the original inputs manually using the [dataset source guide](../docs/datasets.md).

The default glaucoma folder is `data/raw/Glaucoma_GSE241782/`. Alternatively, set `GLAUCOMA_DATA_DIR` in R to use an existing input directory without copying the data. See [execution instructions](../docs/running-the-precheck.md).

Downloaded files under `data/` are excluded from Git; this README is the exception. Derived sample descriptions suitable for version control are stored under `metadata/`. Generated outputs and R checkpoints go under `results/`, which is also excluded.

This repository documents secondary analysis. Experimental data credit belongs to the original study authors, linked through the public accession records.
